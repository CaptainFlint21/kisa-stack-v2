# Components

- Codex Desktop — управляющий интерфейс и локальный исполнитель.
- GitHub fork — долговременная история изменений KISA.
- Kate — удалённый worker через встроенное SSH-подключение Codex Desktop.
- Codex CLI на Kate — CLI/MCP и batch-задачи, когда это действительно требуется.
- LLM Wiki — подтверждённый долговременный контекст без секретов.
