# Codex Desktop stack

Каноническая точка входа для долговременного контекста Codex Desktop.

## Назначение

- Codex Desktop управляет работой на локальном Windows-ПК.
- Kate используется как удалённая Linux-среда для разработки и тестов.
- Проверяемые факты важнее предположений и устаревших заметок.
